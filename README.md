# matsushi_gamecenter

夏休みの自由研究でつくる、Webアプリゲームのリポジトリです。

## きかくシート

[`kikakusho.html`](./kikakusho.html) は、ゲームのアイデアを子どもが自分で書き込むための企画シートです。
ダウンロードしてブラウザで開くか、GitHub Pages公開後はURLで直接アクセスできます。タイトル・あそびかた・操作方法・画面の絵(お絵かき機能つき)などを埋めていくと、そのままゲーム制作の設計図になります。

## Chromebookでのアクセスについて

学校配布のChromebookはネットワーク制限があることが多いため、以下のいずれかの方法を想定しています。

- GitHub Pagesで公開し、URLでアクセスする(要:学校ネットワークでの事前確認)
- ファイルをダウンロードし、`file://` で直接ブラウザで開く(ネット環境に依存しない)
