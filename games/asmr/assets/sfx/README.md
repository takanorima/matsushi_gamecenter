# 効果音ファイル

食べものごとに専用の咀嚼音ファイルを用意しており、それぞれ元の録音から実際に音が鳴っている部分だけを切り出し、音量をそろえてある。

| ファイル | 食べもの | 元の録音 |
| --- | --- | --- |
| `chew_potechi.wav` | ポテチ🥔 | かみくだく音がやや小さめだったので音量を上げてトリミング |
| `chew_chocolate.wav` | チョコレート🍫 | 「パキッ」という一瞬の音だけを切り出し |
| `chew_candy.wav` | パチパチ飴🍬 | 「パチパチ」と鳴り続ける部分をまるごと切り出し |
| `chew_ramen.wav` | ラーメン🍜 | 「ズズッ」というすすり音を2回分切り出し |

`games/asmr/index.html` は、食べものを一口食べるたびに、その食べものに対応するファイルを再生する(`FOODS_MAIN` 配列で emoji と音声ファイルを紐づけている)。ファイルが読み込めない場合は、コードが自動生成した音(WebAudio)で代用する。

## 過去の音源(現在は未使用)

- `chew.wav` / `chew_original.mp3` — 最初にいただいた「きゅうり」の咀嚼音。食べものを一時的に全部きゅうりにしていた時期に使っていたもので、現在の4種類の食べものには使っていない。参照用に残してある。

## 新しい食べもの・音源を追加したいとき

1. このフォルダに音声ファイル(`.wav`推奨)を置く。
2. `games/asmr/index.html` の `FOODS_MAIN` 配列に `{ emoji: "...", sound: "assets/sfx/ファイル名" }` の形で追記する。
3. 録音の前後に無音・環境音が多く入っている場合は、実際に鳴ってほしい部分だけを短く切り出しておくと、連続して食べたときに音がきれいに鳴る。
