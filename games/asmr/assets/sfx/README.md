# 効果音ファイル

- `chew.wav` — ゲームが実際に再生する咀嚼音。`chew_original.mp3`(いただいた元の録音、約5秒)のうち、実際に「かみくだく音」が鳴っている0.40〜0.85秒だけを切り出したもの。元ファイルはほとんどが無音に近い環境音だったため、そのまま一口ごとに再生すると音がかぶって濁ったり、鳴るタイミングが遅れたりしていた。それを直すために短くトリミングした。
- `chew_original.mp3` — いただいた録音そのもの(未加工、参照用に保存)。

`games/asmr/index.html` は起動時に `chew.wav` を読み込もうとし、見つかればそれを再生する。まだ置かれていない/読み込めない場合は、コードが自動生成した音(WebAudio)で代用する。

## 新しい音源に差し替えたいとき

1. このフォルダに `chew.wav`(または`.mp3`)という名前で置く。ファイル名を変える場合は `index.html` 内の `CHEW_SRC` の値も合わせて変更する。
2. 録音の前後に無音・環境音が多く入っている場合は、実際に鳴ってほしい部分だけを短く(0.3〜0.6秒程度)切り出しておくと、連続して食べたときに音がきれいに鳴る。
