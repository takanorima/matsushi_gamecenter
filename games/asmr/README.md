# ASMRゲーム(寛成さん作)

このフォルダで、寛成さんの企画をもとにしたゲームを開発します。
新しいセッションで作業を始めるときは、このREADMEと下記の企画書を読み込んでください。

- 企画書(提出データ): [`submissions/kikakusho_20260816_寛成.html`](../../submissions/kikakusho_20260816_寛成.html)

## 企画の要点

- **タイトル**: ASMRゲーム
- **キャラクター・ストーリー**: ギャル
- **あそびかた**: 指で動かす
- **クリア・ゴール**: 10個食べたらクリア
- **むずかしさ**: かんたん
- **配色**: メイン `#ffd6ff` / サブ `#dcffff`
- **画面の絵**: 企画書内のお絵かき欄を参照

## 状態

実装ずみ。[`index.html`](./index.html) をブラウザで開くと遊べます(外部ファイル・ネット接続不要)。

- 画面下辺のテーブル上のお皿に食べものが乗っていて、ギャルキャラクターの口に指でつまんで運ぶとたべる
- ステージ1〜5まであり、ステージnはクリアに`10n`個、同時にお皿は`n`枚
- 背景にはキラキラとくだものを散りばめて演出
- 咀嚼音は `assets/sfx/chew.mp3` があればそれを再生し、無ければWebAudioで生成した音で代用する(詳細は[`assets/sfx/README.md`](./assets/sfx/README.md))
- キャラクターは寛成さんの手描きスケッチ(丸い輪郭・リボン・ギザギザ前髪・キラキラ星の目・左右非対称のツインテール・大きく開いた口)を解釈したSVGイラスト

### 現在、仮の状態にしているもの

- **食べものは全部きゅうり🥒**: 咀嚼音サンプルが「きゅうりの音」1種類のため、食べものも一時的に全てきゅうりに統一している。他の食材の音や絵に対応する場合は差し替える
- **咀嚼音**: 受け取ったサンプル(`assets/sfx/chew.mp3`)をそのまま使用中。トリミングや音量調整が必要なら教えてください
- **キャラクターの見た目**: 手描きスケッチを写真から解釈してSVGで再現したもの。実物の画像ファイルを直接送ってもらえれば、イラストそのものを埋め込む形に差し替え可能
