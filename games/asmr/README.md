# ASMRゲーム(寛成さん作)

このフォルダで、寛成さんの企画をもとにしたゲームを開発します。
新しいセッションで作業を始めるときは、このREADMEと下記の企画書を読み込んでください。

- 企画書(提出データ): [`submissions/kikakusho_20260816_寛成.html`](../../submissions/kikakusho_20260816_寛成.html)

## 企画の要点

- **タイトル**: ASMRゲーム
- **キャラクター・ストーリー**: ギャル
- **あそびかた**: 指で動かす
- **クリア・ゴール**: 10個食べたらクリア
- **むずかしさ**: かんたん
- **配色**: メイン `#ffd6ff` / サブ `#dcffff`
- **画面の絵**: 企画書内のお絵かき欄を参照

## 状態

実装ずみ。[`index.html`](./index.html) をブラウザで開くと遊べます(外部ファイル・ネット接続不要)。

- ギャルキャラクターの口に、画面に出てくる食べもの(絵文字)を指でつまんで運ぶとたべる
- 10個たべるとクリア画面が出る
- 効果音はWebAudioでその場生成しているので音声ファイル不要
