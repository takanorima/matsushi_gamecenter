# ASMRゲーム(寛成さん作)

このフォルダで、寛成さんの企画をもとにしたゲームを開発します。
新しいセッションで作業を始めるときは、このREADMEと下記の企画書を読み込んでください。

- 企画書(提出データ): [`submissions/kikakusho_20260816_寛成.html`](../../submissions/kikakusho_20260816_寛成.html)

## 企画の要点

- **タイトル**: ASMRゲーム
- **キャラクター・ストーリー**: ギャル
- **あそびかた**: 指で動かす
- **クリア・ゴール**: 10個食べたらクリア
- **むずかしさ**: かんたん
- **配色**: メイン `#ffd6ff` / サブ `#dcffff`
- **画面の絵**: 企画書内のお絵かき欄を参照

## 状態

実装ずみ。[`index.html`](./index.html) をブラウザで開くと遊べます(外部ファイル・ネット接続不要)。

- 画面下辺のテーブル上のお皿に食べものが乗っていて、ギャルキャラクターの口に指でつまんで運ぶとたべる
- ステージ1〜5まであり、ステージnはクリアに`10n`個、同時にお皿は`n`枚
- 食べものはきゅうり🥒・ポテチ🥔・チョコレート🍫・パチパチ飴🍬・ラーメン🍜・唐揚げ🍗の6種類がランダムに出てきて、それぞれ専用の咀嚼音が鳴る(詳細は[`assets/sfx/README.md`](./assets/sfx/README.md))
- 背景にはキラキラとくだものを散りばめて演出
- キャラクターは寛成さんの手描きイラストの実画像([`assets/art/gal_closed.jpg`](./assets/art/gal_closed.jpg) / [`assets/art/gal_open.jpg`](./assets/art/gal_open.jpg))をそのまま埋め込んでおり、食べるたびに口を閉じたver.と開けたver.が切り替わる(解像度は表示用に軽量化ずみ、元画像はトリミングのみで線は加工していない)
- 画面右上に「Kansei 作」のクレジットを常時表示
