# ASMRゲーム(寛成さん作)

このフォルダで、寛成さんの企画をもとにしたゲームを開発します。
新しいセッションで作業を始めるときは、このREADMEと下記の企画書を読み込んでください。

- 企画書(提出データ): [`submissions/kikakusho_20260816_寛成.html`](../../submissions/kikakusho_20260816_寛成.html)

## 企画の要点

- **タイトル**: ASMRゲーム
- **キャラクター・ストーリー**: ギャル
- **あそびかた**: 指で動かす
- **クリア・ゴール**: 10個食べたらクリア
- **むずかしさ**: かんたん
- **配色**: メイン `#ffd6ff` / サブ `#dcffff`
- **画面の絵**: 企画書内のお絵かき欄を参照

## 状態

実装ずみ。[`index.html`](./index.html) をブラウザで開くと遊べます(外部ファイル・ネット接続不要)。

- 画面下辺のテーブル上のお皿に食べもの(おかず)が乗っていて、ギャルキャラクターの口に指でつまんで運ぶとたべる
- ステージ1〜5まであり、ステージnはクリアに`10n`個、同時にお皿は`n`枚
- 背景にはキラキラとくだものを散りばめて演出
- 効果音はWebAudioでその場生成。`assets/sfx/chew.mp3` を置けばそちらを優先して咀嚼音として再生する(詳細は[`assets/sfx/README.md`](./assets/sfx/README.md))

- **キャラクターの見た目**: 現状はプレースホルダーのSVGイラスト。手描きイラストを受け取り次第、差し替える
- **咀嚼音の音源**: 受け取り次第 `assets/sfx/chew.mp3` に配置する
