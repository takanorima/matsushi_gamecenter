# 動物育成ゲーム(花乃子さん作)

このフォルダで、花乃子さんの企画をもとにしたゲームを開発します。
新しいセッションで作業を始めるときは、このREADMEと下記の企画書を読み込んでください。

- 企画書(提出データ): [`submissions/kikakusho_20260816_花乃子.html`](../../submissions/kikakusho_20260816_花乃子.html)

## 企画の要点

- **タイトル**: 動物育成ゲーム
- **キャラクター・ストーリー**: 絵文字の動物に餌をあげる。餌をあげるとレベルが上がる。レベルが上がると動物の種類や、餌の種類が増える。
- **あそびかた**: 企画書内のお絵かき欄を参照
- **うごかしかた**: Aで餌をあげる
- **クリア・ゴール**: ライオンまで餌をあげたらクリア
- **むずかしさ**: ふつう
- **配色**: メイン `#a7c6ff` / サブ `#cbf0ff`
- **画面の絵**: 企画書内のお絵かき欄を参照

## 状態

- ゲーム本体を実装済み: [`index.html`](./index.html)(GitHub Pages公開後は `games/animal/` 以下のURLで直接あそべる)
- どうぶつ: 🐭ねずみ → 🐹ハムスター → 🐰うさぎ → 🐱ねこ → 🐶いぬ → 🦁らいおん の6段階。えさをあげる回数を重ねるとレベルアップし、えさの種類も変わっていく。ライオンまで育てるとクリア。
- 操作: 企画書どおり画面の「A」ボタン(またはキーボードのAキー)でえさをあげる。タップ操作にも対応。
- 進行状況はブラウザの localStorage に自動保存される。
- iOSアプリ化: [`ios-app/`](./ios-app/) に、このゲームをそのままiOSアプリにするためのCapacitorプロジェクト(Xcodeプロジェクト一式)を用意済み。ビルド・実機確認にはmacOS + Xcodeが必要なため、詳しくは [`ios-app/README.md`](./ios-app/README.md) を参照。
