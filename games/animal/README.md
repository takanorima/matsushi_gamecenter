## 企画の要点

- **タイトル**: 動物育成ゲーム
- **キャラクター・ストーリー**: 絵文字の動物に餌をあげる。餌をあげるとレベルが上がる。レベルが上がると動物の種類や、餌の種類が増える。
- **あそびかた**: 企画書内のお絵かき欄を参照
- **うごかしかた**: Aで餌をあげる
- **クリア・ゴール**: ライオンまで餌をあげたらクリア
- **むずかしさ**: ふつう
- **配色**: メイン `#a7c6ff` / サブ `#cbf0ff`
- **画面の絵**: 企画書内のお絵かき欄を参照
