## 企画の要点(初期案・元の企画書)

- **タイトル**: 動物育成ゲーム
- **キャラクター・ストーリー**: 絵文字の動物に餌をあげる

- **むずかしさ**: ふつう

その後、下記のとおりクリア条件などを「コレクション方式」に仕様変更した。

## 仕様(コレクション方式)

- 動物は全部で **120種類**登場する。えさをあげるたびに、ランダムで動物が現れる。
- 抽選は「未収集の動物が70%の確率で優先的に出やすい」重み付き抽選。すでに集めた動物も30%の確率で再登場する(何度も登場OK)。
- 1匹の動物に必要な回数だけ餌をあげ終えると、その動物を図鑑に登録(コレクション)し、**レベルが1上がる**。
- **レベルが上がるほど、1匹を集めるのに必要な餌の回数も増えていく**(最初は3回、15レベルごとに+1回、最大9回まで)。
- レベルが上がると、あげられる**餌の種類も増える**(🍖おにく → 🐟さかな → 🥕にんじん … 全10種類)。餌は画面下でえらべて、実際にあげる操作はキーボードの **X キー**。
- 餌をあげ終わった動物は、いちど小さく縮んでから「図鑑をみる」ボタンへ飛んでいくアニメーションで登録される。
- 画面上部の「📖 図鑑をみる」から、集めた動物一覧(チェックリスト形式の図鑑)を確認できる。
- 画面上部の「🏠 おへやをみる」から、集めた動物たちが空と芝生のシーンの中でふわふわ暮らしている「どうぶつのおへや」を見られる(「育ててる感」を出すために追加)。
- **クリア・ゴール**: 120種類ぜんぶ集めて図鑑をコンプリートしたらクリア。

## 実装内容

- [`index.html`](./index.html) がゲーム本体(外部依存なしの単一HTML)。
- 画面下でえさをえらび、キーボードの X キーを押すと、その場にいる動物に餌をあげられる。
- 餌をあげ終わると、その動物が縮んで図鑑へ飛んでいくアニメーションとレベルアップ演出が出て、未収集なら「NEW!」表示とともに図鑑・おへやに登録される。
- 120種類すべて集めるとクリア画面(紙吹雪演出つき)が表示され、「もういちど あそぶ」で最初からやり直せる。
