# 動物育成ゲーム(花乃子さん作)

このフォルダで、花乃子さんの企画をもとにしたゲームを開発しています。
新しいセッションで作業を始めるときは、このREADMEと下記の企画書を読み込んでください。

- 企画書(提出データ): [`submissions/kikakusho_20260816_花乃子.html`](../../submissions/kikakusho_20260816_花乃子.html)

## 企画の要点

- **タイトル**: 動物育成ゲーム
- **キャラクター・ストーリー**: 絵文字の動物に餌をあげる
- **あそびかた**: Aで餌をあげる
- **クリア・ゴール**: ライオンまで餌をあげたらクリア
- **むずかしさ**: ふつう
- **配色**: メイン `#a7c6ff` / サブ `#cbf0ff`
- **画面の絵**: 企画書内のお絵かき欄を参照(キャラ・えさ・「次のレベルまであと◯回」の進捗表示)

## 実装内容

- [`index.html`](./index.html) がゲーム本体(外部依存なしの単一HTML)。
- 「🍖 えさをあげる」ボタン(タップ / クリック / Space・Enterキー)を押すと動物に餌をあげられる。
- 餌をあげるたびに進化ゲージが進み、こねこ🐱 → ねこ🐈 → とら🐯 → ライオン🦁 の順に育っていく。
- ライオンまで育てるとクリア画面が表示され、「もういちど あそぶ」で最初からやり直せる。
